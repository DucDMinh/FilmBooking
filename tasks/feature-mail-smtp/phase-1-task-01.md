## Thiết kế (dispatcher chốt, giữ gọn — dự án demo)

1. **Dependency:** thêm `nodemailer` (dependencies) + `@types/nodemailer` (devDependencies) vào `apps/api` bằng `pnpm --filter @filmbooking/api add ...`; **gỡ `resend`** khỏi `apps/api/package.json`. Cập nhật `pnpm-lock.yaml`. Lưu ý `apps/api/package.json` đang có thay đổi của USER ở script `start` (`--env-file=../../.env.local`) — **GIỮ NGUYÊN** thay đổi đó, chỉ thêm/bớt dependency.
2. **Env (`apps/api/src/config/env.ts`):** thêm các biến optional: `SMTP_HOST`, `SMTP_PORT` (coerce int 1–65535, optional), `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`. Gỡ `RESEND_API_KEY`. Không thêm ràng buộc production (đó là scan #5, ngoài phạm vi). Cập nhật comment đầu `envSchema` nếu nhắc mail.
3. **Mail transport (`mail.module.ts` + `mail.service.ts`):**
   - Token đổi `RESEND_CLIENT` → `MAIL_TRANSPORT` (Symbol, export từ `mail.service.ts`). Kiểu tối thiểu `MailTransport = { sendMail(options): Promise<{ messageId: string; rejected?: unknown[] }> }` để test không phụ thuộc nodemailer.
   - Export hàm thuần `createMailTransport(env): MailTransport | null` (đặt trong `mail.module.ts` hoặc file `mail.transport.ts` cạnh đó): `null` khi thiếu `SMTP_HOST`; ngược lại `nodemailer.createTransport({ host, port: SMTP_PORT ?? 465, secure: port === 465, auth: SMTP_USER ? { user, pass: SMTP_PASS } : undefined, connectionTimeout: 10_000, greetingTimeout: 10_000, socketTimeout: 20_000 })`. (Timeout để cron `/jobs/send-emails` không treo khi SMTP chết.)
   - `MailService.sendEmail`: `from = options.from ?? env.SMTP_FROM ?? (env.SMTP_USER ? \`FilmBooking <${env.SMTP_USER}>\` : "FilmBooking <no-reply@filmbooking.local>")`. Không có transport: `NODE_ENV === "test"` → trả `{ id: "mock-email-…" }` như cũ; còn lại `throw new Error("SMTP is not configured (SMTP_HOST)")`. Có transport: `await transport.sendMail({ from, to, subject, html, text })`; lỗi → `throw new Error(\`SMTP send failed: ${msg}\`)` (giữ log `logger.error`, **KHÔNG log SMTP_PASS**); nếu `rejected` chứa người nhận → throw; không có `messageId` → throw (giữ hành vi cũ "missing message ID"). Giữ nguyên `sendOutboxEmail` và `renderTemplate`.
   - `MailModule` providers/exports dùng `MAIL_TRANSPORT` thay `RESEND_CLIENT`.
4. **Callers / test cũ:** cập nhật mọi chỗ dùng `RESEND_CLIENT`/`resend` (`apps/api/test/outbox-job.e2e-spec.ts`, `apps/api/test/integration/helpers/app-harness.ts`, mọi test env có `RESEND_API_KEY`) sang `MAIL_TRANSPORT`/`SMTP_*`. **Không xoá/nới assertion.** Comment trong `jobs.controller.ts` "qua Resend" → "qua SMTP".
5. **Test mới (đỏ trước fix, xanh sau):** `apps/api/test/mail-service.spec.ts` (hoặc cạnh module): (a) `createMailTransport` trả `null` khi thiếu `SMTP_HOST`; với host/port 465 gọi `nodemailer.createTransport` với `secure: true`, port 587 → `secure: false`, có `auth` khi có `SMTP_USER` (mock `nodemailer`); (b) `sendEmail` gọi `sendMail` đúng from/to/subject/html/text; from lấy `SMTP_FROM` > `SMTP_USER` > mặc định; (c) lỗi SMTP → throw `SMTP send failed`; (d) `rejected` chứa người nhận → throw; (e) không transport: test env → id mock, production/development → throw `SMTP is not configured`; (f) `sendOutboxEmail` render + gửi (kind `ACCOUNT_LOCKED_ALERT`).
6. **Cấu hình + docs (as-built, không đụng intent docs):**
   - `.env.example` + `.env.local.example`: thay `RESEND_API_KEY`/`RESEND_FROM_EMAIL` bằng `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` (kèm comment ngắn: Gmail = `smtp.gmail.com` / 465 / App Password; Resend = `smtp.resend.com` / 465 / user `resend` / pass = API key).
   - `README.md` bảng biến: thay dòng `RESEND_API_KEY` bằng các biến `SMTP_*`, bỏ ghi chú "code không đọc RESEND_FROM_EMAIL".
   - `docs/dev-setup.md`: (i) danh sách biến; (ii) mục "Gửi mail thật bằng Gmail" (bật 2FA → App Password → điền `SMTP_*` vào `.env.local`; from sẽ bị Gmail ghi đè thành chính tài khoản; giới hạn ~500 mail/ngày; không dùng cho production); (iii) hướng dẫn SMTP cho **Supabase Auth**: local sửa khối `[auth.email.smtp]` trong `supabase/config.toml` (`enabled=true`, user/admin_email, `pass` đọc từ `env(SMTP_PASS)` đặt trong `supabase/.env`) rồi `pnpm db:stop && pnpm db:start`; (iv) local không có cron gọi job → gọi tay `curl -X POST http://localhost:3001/jobs/send-emails -H "x-job-secret: <JOB_SECRET>"` (và nhắc Vault secret `api_base_url`/`job_secret` nếu muốn chạy pg_cron); (v) email Auth local mặc định nằm ở Mailpit `http://127.0.0.1:54324`, không phải hộp thư thật.
   - `docs/DESIGN.md` (dòng 17, 42) và `docs/API_SPEC.md` (dòng ~260): "Resend" → "SMTP (nodemailer)". `docs/changes/TECHNICAL_REQUIREMENT_GAPS.md`: ghi mục `RESEND_FROM_EMAIL` đã giải quyết (không còn biến này; thay bằng `SMTP_FROM`).
